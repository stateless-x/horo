# ChatGPT image prompts: monthly page art (2026-10-24)

## How to use this file with ChatGPT

1. Open a new ChatGPT chat with image generation.
2. Attach the same three reference images to every request: the moon ticket, the heart ticket, and one mascot picture. These set the style.
3. Paste the INSTRUCTION below once, as the first message of the chat. It tells ChatGPT how to behave for all the images.
4. Then send the images one at a time: paste one SUBJECT, then the STYLE block right after it, in the same message.
5. When an image comes back, check it against the checklist at the bottom. If it is wrong, reply with the fix sentence, don't start a new chat.
6. Save each image under the filename shown in the heading, and send the files to Claude.

## INSTRUCTION (paste once, first)

```text
You are my illustrator for a Thai astrology website. I will send you one subject at a time. For every image: use the attached reference images as the exact style guide (same ticket look, same outline, same palette). Output exactly one square PNG, 1024 x 1024 pixels, on a perfectly flat solid background color #F2EFFE with no gradient, no shadow on the background and no scenery, because I cut the background out afterwards. Never add text, letters, numbers, logos or a mascot unless the subject says so. Count objects carefully when the subject gives a number. After each image, say in one line how many items you drew if the subject had a count, and nothing else. Wait for my next subject.
```

## STYLE block (paste after every SUBJECT)

```text
Square illustration, exactly 1024 x 1024 pixels, for a Thai astrology website. Background: one perfectly flat solid color #F2EFFE, no gradient, no vignette, no shadow on the background, no scenery, so it can be cut out cleanly. Match the attached references exactly in style: soft purple and gold palette (#6B21A8, #A855F7, #E9D5FF, warm gold), the same wobbly dark-brown outline, hand-drawn storybook line, flat soft shading, no photorealism, no neon. The artwork stays centered with at least 100 px of clean margin on every side. No text, no letters, no numbers, no logos, no mascot.
```
