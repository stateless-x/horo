### คู่ที่ใช่ (top 3)

บอกเป็น type ที่เข้ากันดี 3 อันดับ ไม่ใส่ชื่อตัวละคร คนอ่านจะได้เช็กกับ type ของแฟนหรือเพื่อนได้ตรงๆ

วิธีเลือก มาจากตารางความเข้ากันของ MBTI ที่แฟนนิยมแชร์กัน
- **อันดับ 1-2** คือคู่ที่ตารางให้ว่าเข้ากันดีที่สุด ทุกคู่ต่างกันที่ E/I คือคนหนึ่งเปิด อีกคนเก็บตัว เลยเติมกันพอดี
- **อันดับ 3** คือ type ที่ตารางให้ว่าเข้ากันดีรองลงมา ส่วนใหญ่เป็น type ที่ต่างกันแค่ 1 ตัวอักษร

ตารางนี้เป็นของแฟน ไม่ใช่หลักวิชาการ และ MBTI ทำนายความรักไม่ได้

## เหตุผลรายตัว

แต่ละตัวอธิบายทีละตัวอักษร
- **E/I:** ได้พลังจากคนอื่น หรือจากการอยู่กับตัวเอง
- **S/N:** มองสิ่งที่อยู่ตรงหน้า หรือมองภาพใหญ่และความเป็นไปได้
- **T/F:** ตัดสินใจด้วยเหตุผล หรือด้วยความรู้สึกของคน
- **J/P:** ชอบมีแผนและกฎ หรือชอบปรับตามสถานการณ์

ถ้าตัวอักษรไหนในเรื่องไม่มีหลักฐานพอ เขียนไว้ว่า "เดา"

### 1. Chiikawa: INFP (สูง)

ในเรื่อง Chiikawa ขี้กลัวและร้องไห้ง่าย พูดได้แค่เสียงสั้นๆ แต่เมื่อเพื่อนเจออันตรายจะกล้าขึ้นมาเอง
- **I** เก็บความรู้สึกไว้ในใจ แสดงออกด้วยน้ำตามากกว่าคำพูด
- **N** เว็บแฟนอธิบายว่ามีโลกข้างในและความฝันเล็กๆ ของตัวเอง ข้อนี้ในเรื่องเห็นไม่ชัด
- **F** ใช้หัวใจนำ ใจอ่อน ไม่ปฏิเสธใคร
- **P** ไม่ได้วางแผนชีวิต ทำไปตามวันและปรับตัวเมื่อเจอเรื่อง

เว็บแฟนทั้งสองเว็บให้ INFP บางคนว่าเป็น ISFP

### 2. Hachiware: ESFJ (สูง)

Hachiware เป็นตัวเดียวในแก๊งที่พูดเป็นประโยค เป็นคนคุยแทนเพื่อน ปลอบ Chiikawa เวลาร้องไห้ ชอบถ่ายรูป และนับถือ Rakko เป็นอาจารย์
- **E** เข้าหาคนก่อน คุยกับทุกคน เป็นคนพูดแทนเพื่อน
- **S** สนใจเรื่องตรงหน้าในชีวิตประจำวัน เช่น ถ่ายรูป ทำงาน กินข้าว
- **F** อ่านอารมณ์เพื่อนเก่ง และเลือกพูดให้เพื่อนสบายใจ
- **J** ชอบให้ทุกคนอยู่กันดี คอยจัดบรรยากาศให้เรียบร้อย

เว็บแฟนให้ ESFJ บางคนว่าเป็น ENFP หรือ ENTP เพราะ Hachiware ชอบเล่นคำและมีความคิดแปลกใหม่

### 3. Usagi: ESTP (สูง)

Usagi ตะโกนเสียงแปลกๆ กระโดดไปมา ทำอะไรไม่บอกใคร กล้าที่สุดในแก๊ง พาเพื่อนไปสำรวจ และชอบกินมาก
- **E** แสดงออกเต็มที่ เสียงดัง อยู่ไม่นิ่ง
- **S** ใช้ร่างกายและประสาทสัมผัส ทั้งกิน สู้ และวิ่ง
- **T** ตัดสินใจเร็ว ไม่ลังเลด้วยความรู้สึก
- **P** ทำทันทีที่เห็นโอกาส ไม่มีแผน

เว็บแฟนทั้งสองเว็บให้ ESTP

### 4. Momonga: ENTP (สูง)

Momonga อยากเป็นจุดสนใจ งอแง และเลียนแบบความน่ารักของ Chiikawa เพื่อเอาสิ่งที่ตัวเองต้องการ
- **E** ต้องการคนดู ต้องการความสนใจ
- **N** หาทางใหม่ๆ เพื่อให้ได้สิ่งที่ต้องการ เช่น ใช้ความน่ารักเป็นกลยุทธ์
- **T** เว็บแฟนบอกว่าเป็นตัวยั่วยุและชอบเถียง ข้อนี้ในเรื่องเห็นไม่ชัด
- **P** อารมณ์เปลี่ยนเร็ว คาดเดาไม่ได้

เว็บแฟนทั้งสองเว็บให้ ENTP

### 5. Rakko: ISTJ (กลาง)

Rakko เป็นนักล่าอันดับหนึ่ง ใจดีและใจกว้าง ช่วยฝึกการล่าให้ Chiikawa กับเพื่อน หน้าเคร่งขรึม แต่ชอบของหวาน และร้องเพลงตอนขับรถเพื่อไม่ให้หลับ
- **I** อยู่เงียบๆ ไม่ได้อยู่กับแก๊ง ออกมาเมื่อมีงาน
- **S** เก่งด้วยการฝึกซ้อมจริง ไม่ใช่ด้วยทฤษฎี
- **T** ให้คำแนะนำตรงๆ ไม่ยืดเยื้อ
- **J** มีวินัย และรักษาอันดับหนึ่งไว้ได้ด้วยความสม่ำเสมอ

Yoho HK ให้ ISTJ บางคนว่าเป็น INTJ เพราะเป็นนักวางแผน

### 6. Shisa: ENFJ (กลาง)

Shisa ทำงานหลายที่ ขอเป็นลูกศิษย์ Ramen no Yoroi-san จนได้ใบรับรองระดับซูเปอร์พาร์ทไทม์ และสอนเพื่อนเรื่องรสชาติอย่างตั้งใจ
- **E** ทำงานกับคน ชอบทำงานกับลูกค้าและอาจารย์
- **N** มีเป้าหมายระยะยาว อยากเป็นเชฟราเมนที่ดี และฝึกจนได้ใบรับรอง
- **F** ทำเพราะอยากให้คนอื่นมีความสุข และอยากให้อาจารย์ภูมิใจ
- **J** ตั้งใจ มีระเบียบ ทำตามขั้นตอนการฝึก

Yoho HK ให้ ENFJ

### 7. Kurimanju: ISTP (กลาง)

Kurimanju ดื่มเบียร์แล้วถอนหายใจเสียงดัง พูดน้อย อยู่เงียบๆ มีใบอนุญาตดื่มเหล้า แบ่งของกินให้เพื่อน และช่วยตอนสำคัญ
- **I** มีความสุขกับการอยู่คนเดียว
- **S** เพลินกับสิ่งตรงหน้า เช่น รสชาติ เครื่องดื่ม และช่วงเวลานั้น
- **T** ไม่แสดงอารมณ์ ช่วยด้วยการลงมือทำ ไม่ใช่ด้วยคำปลอบ
- **P** ชิล ไม่รีบ ไม่มีแผน

## ขายดวงต่อจากโพสต์

### หลักการ

**ภาพ Chiikawa ห้ามมีปุ่มขาย ราคา หรือลิงก์**
- ภาพเป็นแฟนอาร์ต ถ้าใส่ของขายลงไป จะกลายเป็นการใช้ตัวละครโปรโมตสินค้า และเป็นเหตุให้โดนรายงานได้ง่ายที่สุด
- คนแชร์ภาพที่ดูเป็นของแฟนทำ มากกว่าภาพที่ดูเป็นโฆษณา

การขายจึงแยกเป็น 2 ชั้น
1. **ในภาพ** มีแค่บรรทัด "ราศี" หรือ "เคล็ดมู" ให้คนรู้ว่าเพจนี้ดูดวง แต่ไม่มีการขาย
2. **ใต้โพสต์** ตอบโพสต์ตัวเอง ใช้ภาพของมูมู่ (ตัวละครของ Horo) แล้วใส่ลิงก์ที่นี่

### ชั้น 1: ราศีในภาพ

ใส่บรรทัดราศีเล็กๆ ล่างสุดของแผ่น 1-8 ข้อความอยู่ในหัวข้อ "ราศี" ของแต่ละแผ่นด้านบน
แผ่น 9-16 ใช้บรรทัด "เคล็ดมู" แทน เป็นคำแนะนำสายมูสั้นๆ ที่เข้ากับนิสัยของ type นั้น
- คนอ่านจะเทียบราศีตัวเองกับน้องทันที เช่น "เราก็ Taurus เหมือน Chiikawa" ได้ทั้งเมนต์และความรู้สึกว่าเพจนี้สายมู

### ชั้น 2: ตอบใต้โพสต์ตัวเอง

ตอบโพสต์ตัวเองทันทีหลังโพสต์ ใช้ภาพมูมู่แทน Chiikawa
ลิงก์ที่อยู่ในการตอบกลับ X ลดการมองเห็นน้อยกว่าลิงก์ในโพสต์หลัก

**ภาพ:** มูมู่ถือลูกแก้ว ข้างๆ มีป้าย "MBTI บอกนิสัย วันเกิดบอกจังหวะชีวิต"
สไตล์สีไม้เหมือนชุด Chiikawa จะได้ดูเป็นชุดเดียวกัน
ดูหน้าตามูมู่ที่ `horo-fe/docs/character-bible.md`

**ข้อความตอบกลับ ใช้ได้ 2 แบบ**

แบบ A: ชวนดูดวงคู่ (เข้ากับธีม "คู่ที่ใช่" มากที่สุด)
```
MBTI บอกว่านิสัยเข้ากันไหม
แต่ดวงคู่จากวันเกิด บอกว่าปีนี้สองคนจะเจออะไรด้วยกัน 💞

ลองดูดวงคู่ของคุณกับเขา 🔮
สายมู.com
```

แบบ B: ชวนอ่านเรื่อง type ตัวเองบนเว็บ (คนเข้าเว็บก่อน แล้วค่อยเจอดวง)
```
อยากรู้จัก type ตัวเองให้ลึกกว่านี้?
มูมู่เขียนไว้ครบทั้ง 16 type 🤍

สายมู.com/mbti
```
ใต้โพสต์ของแต่ละวัน ใส่ลิงก์ `/mbti/<type>` ของ 4 type ในวันนั้นแทนได้ เช่น `สายมู.com/mbti/infp`
หน้านี้มีอยู่แล้วบนเว็บ และท้ายหน้ามีปุ่มพาไปเริ่มดูดวง (`/onboarding`)

**ห้ามใช้:** "MBTI ของคุณบอกดวง..." หรือ "ดูดวงตาม MBTI"
เพราะเว็บไม่ได้ใช้ MBTI ทำนาย ถ้าพูดแบบนี้คนกดเข้าไปแล้วจะรู้สึกโดนหลอก
