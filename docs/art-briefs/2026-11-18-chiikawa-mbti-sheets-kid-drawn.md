# Chiikawa × MBTI: แบบ "เด็กวาด" (ทางเลือก)

ภาพชุดเดียวกับ [2026-11-18-chiikawa-mbti-sheets.md](2026-11-18-chiikawa-mbti-sheets.md) แต่เปลี่ยนสไตล์เป็นภาพที่ดูเหมือนเด็กประถมวาดแบบไม่เก่ง
ความตลกอยู่ที่ "วาดไม่สวย แต่ตั้งใจมาก" คนเห็นแล้วจะขำและอยากแชร์

**ไฟล์นี้มีสไตล์ การจัดหน้า ท่า และ prompt เต็มของแต่ละแผ่น** ส่วนนี้ยังอยู่ที่ไฟล์หลักที่เดียว
- type ของแต่ละตัว เหตุผล และแหล่งอ้างอิง
- แผนโพสต์ แคปชัน และการขายดวงต่อจากโพสต์

ข้อความบนภาพ (ฉายา นิสัย คู่ที่ใช่ ราศีหรือเคล็ดมู) ก๊อปจากไฟล์หลักมาใส่ใน prompt ของแต่ละแผ่นแล้ว
**ถ้าแก้ข้อความในไฟล์หลัก ต้องแก้ใน prompt ของไฟล์นี้ด้วย** ไม่อย่างนั้นสองไฟล์จะไม่ตรงกัน

## สไตล์ภาพ

### หลัก

- **อุปกรณ์** สีเทียนกับปากกาเมจิก ไม่ใช่สีไม้
- **กระดาษ** กระดาษ A4 สีขาว ยับนิดๆ หรือกระดาษสมุดมีเส้นบรรทัดสีฟ้า ให้เหมือนสแกนหรือถ่ายรูปมา
- **เส้น** สั่น หนาบางไม่เท่ากัน เส้นไม่ต่อกันบางจุด วาดทับซ้ำ 2-3 รอบ
- **ลงสี** ระบายวนๆ เลยขอบเยอะ เหลือช่องขาวเป็นหย่อมๆ บางจุดใช้สีผิดนิดหน่อย
- **สัดส่วน** หัวใหญ่เกินตัว แขนขาเป็นเส้นหรือแท่งสั้นๆ ตาสองข้างไม่เท่ากัน มือเป็นวงกลมหรือมีนิ้วเกิน
- **ท่า** หันหน้าตรงเกือบทุกแผ่น เพราะเด็กวาดท่าเอียงหรือท่าซับซ้อนไม่เป็น
- **ฉาก** แบบเด็กวาดคลาสสิก มีแถบฟ้าด้านบน แถบหญ้าสีเขียวด้านล่าง และพระอาทิตย์มีหน้ายิ้มที่มุมบน (เลือกมุมที่ไม่ทับข้อความ)
- **ขนาด** 1600×900 (16:9) เท่ากับไฟล์หลัก

### ต้องจำได้ว่าเป็นตัวไหน

### ข้อความบนภาพ

ข้อความเขียนด้วยลายมือเด็ก แต่ **ต้องอ่านออกบนมือถือ**
- ตัวอักษรใหญ่กว่าไฟล์หลัก ใช้ปากกาเมจิกสีเข้ม
- ตัวอักษรเอียงขึ้นลงได้ ขนาดไม่เท่ากันได้ แต่ห้ามสะกดผิด โดยเฉพาะรหัส type
- ไม่มีการขีดฆ่า ไม่เขียนทับ ไม่มีเครื่องหมายกากบาทบนข้อความ (โลโก้ 𝕏 หน้าชื่อบัญชีใส่ได้ตามปกติ)
- ทุกบรรทัดเป็นลายมือ ไม่ใช้ฟอนต์

## การจัดหน้า

```
┌──────────────────────────────────────────────────┐
│ ☀️(ยิ้ม)   ~~~ แถบฟ้า ~~~       I N F P  (สีรุ้ง) │
│                                  ใจบางแต่ใจกล้า  │
│   [ตัวละคร หันหน้าตรง]           1. นิสัย 1       │
│      ↑                           2. นิสัย 2       │
│  นี่คือ ชิคาวะ                 3. นิสัย 3       │
│        💞 คู่ที่ใช่ ENFJ · ENTJ · INFJ                    │
│ ~~~~~ หญ้าสีเขียว ~~~~~ ♉ Taurus · คน Taurus ใจเย็น อดทน ... │
│                              𝕏 @Saimoo_official  │
└──────────────────────────────────────────────────┘
```

- **รหัส type** สีเทียนคนละสีทุกตัวอักษร เหมือนเด็กเขียนสีรุ้ง ตัวใหญ่สุดในภาพ
- **นิสัย** เขียนเป็นข้อ 1-2-3 แบบสมุดการบ้าน
- **คู่ที่ใช่** 3 type เรียงตามอันดับ วาดหัวใจเล็กๆ หน้าอันดับ 1
- **ราศี** บรรทัดล่างสุด วาดสัญลักษณ์ราศีตัวใหญ่แบบเด็กวาด เช่น ♉ เป็นหัววัว ไม่เขียนวันเกิดตัวละคร แผ่น 9-16 ไม่มีวันเกิด ใช้ 🔮 เคล็ดมู แทน

## ลายเซ็น

- **ใส่ที่เดียวทั้งภาพ คือมุมล่างขวา** ห้ามใส่ซ้ำที่บรรทัดคู่ที่ใช่หรือที่อื่น
- เขียน `𝕏 @Saimoo_official` (โลโก้ X ตามด้วยชื่อบัญชี) ที่มุมล่างขวา ด้วยปากกาเมจิกสีเข้ม
- ไม่มีลายน้ำบนภาพ ไม่มีคำว่า "วาดโดย"

## Prompt ภาษาอังกฤษ (สร้างทั้งภาพในครั้งเดียว)

**สร้างทั้งภาพในครั้งเดียว รวมข้อความทั้งหมด** ทั้งตัวละคร ฉากหลัง ข้อความ และ `𝕏 @Saimoo_official`
- ห้ามสร้างภาพเปล่าแล้วเอาข้อความมาแปะทีหลัง เพราะข้อความที่แปะจะดูเป็นฟอนต์ ไม่เข้ากับลายมือในภาพ
- prompt ของแต่ละแผ่นด้านล่างครบในตัวแล้ว (ฉาก + ข้อความทุกบรรทัด + สไตล์) ก๊อปทั้งกล่องไปวางทีละแผ่น ไม่ต้องส่งทั้งไฟล์
- ถ้าภาษาไทยในภาพสะกดผิด หรือข้อความซ้ำ ให้สร้างใหม่ทั้งภาพ อย่าแก้ด้วยการแปะทับ

สไตล์ที่ใช้ในทุก prompt (อยู่ท้ายกล่องของแต่ละแผ่นแล้ว):

```
crude childlike crayon and marker drawing, looks drawn by a 6-year-old who is not good at drawing,
wobbly shaky lines, wrong proportions, oversized head, stick-like arms and legs, uneven eye sizes,
scribbly crayon coloring going far outside the lines, patches of white paper left unfilled,
simple front-facing pose, blue sky strip at the top, green grass strip at the bottom,
smiling sun with rays in a top corner, on slightly wrinkled white printer paper, flat scan,
16:9 landscape, character on the left half, text on the right, no watermark
```

ถ้าภาพที่ได้ยังดูสวยเกินไป เพิ่มคำว่า `amateur, messy, imperfect, kindergarten art`
ข้อความทุกตัวในภาพต้องดูเป็นลายมือเด็กมือเดียวกับภาพ รวมถึงตัวอักษรบนพร็อพ เช่น "1" บนเหรียญ "งาน" บนป้าย "郎" บนป้ายร้าน และ "ปู้ฮ่า~"
